# Voice Navigation Toolkit

An embeddable voice navigation toolkit for accessible web interaction.

## Current Features

- Scan interactive elements from the DOM
- Number interactive elements
- Find elements by label
- Click elements by number or label
- Focus input elements by label
- Scroll the page using commands
- Parse natural command strings into actions and targets

## Current Commands

- `click 3`
- `click login`
- `click add to cart`
- `focus email`
- `scroll up`
- `scroll down`
